# 車検時期・具体的満了日判定 テスト結果

実施日: 2026-08-02

## 不具合

車種、車検、具体的な満了日、都合確認を同じ発話で案内しても、「近い」または「時期」がないため車検案内が未達となり、お客様が「はい？ ご用件は何ですか？」と聞き返していた。

## 修正

- 登録車種と車検を伝え、登録済みの具体的な満了日を案内した場合は、車検時期の案内として認識
- 同じ発話に含まれる都合確認と満了日案内も連続して判定
- 車検時期も満了日もない不十分な案内は、従来どおり未達

## 結果

- 画像と同等の複合発話: 車検案内・都合確認・満了日案内をすべて認識
- 従来表現「ヤリスの車検時期が近くなりました」: 認識
- 不十分な表現「ヤリスの車検のご案内です」: 未達
- JavaScript構文検査: 合格
- QAテスト: 13件すべて合格
- `git diff --check`: 合格
