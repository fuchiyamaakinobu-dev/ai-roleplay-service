# 予約承諾後のマイク自動再開テスト

実施日: 2026-08-29

## 対象

- AIお客様「では、その日でお願いします。」の後、スタッフが「かしこまりました。」と発話する流れ
- AIお客様の返答を省略してスタッフの音声入力を継続する処理
- 直前の音声認識停止と次の開始が重なる場合

## 確認内容

- 予約確定後の単独の「かしこまりました。」が、AI音声を再生せず音声入力継続へ進む
- `speechRecognition.start()`が一度`InvalidStateError`になっても120ミリ秒後に再試行する
- 再試行成功後、内部の認識状態とマイクボタンがONになる
- 手動停止時は保留中の再試行タイマーを解除する
- 会話進行、採点条件、AIお客様発話、MP3を変更しない

## 結果

- 専用自動テスト: 合格
- JavaScript構文確認: 合格
- 全回帰テスト: 45本すべて合格
- 12カ月点検音声監査: 51件すべて登録済み・MP3あり・文面一致
- `git diff --check`: 合格
