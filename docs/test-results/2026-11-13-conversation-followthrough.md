# 2026-11-13 実会話処理の確認・修正

対象：12万km・引取納車の模範会話を入力する本番JavaScriptの返答処理。音声認識・MP3再生・実LLMサービス自体のテストではない。

## 再現した原因
- 読点で最後の質問を切り出し、ガラス・灯火類の部位名や連絡先の主語を落としていた。
- 店舗名への質問の抑止判定が会話全体を検索し、冒頭の本別店の名乗りを近隣店舗への回答としていた。
- 予約後の既出工程抑止が発話全体のお礼を検知し、納車受取質問・最終確認でも無応答になった。
- 「車検以外にご希望の作業」「このまま予約の手続きを進めても」「引き取りのご希望日」「住所に変更はありませんか」の既存フォールバックが不足。

## 検証
- 新規198条件成功。27スタッフ発話を模擬LLM選択・保留・OFF・通信失敗の4経路で再生。本番addMessage/commitMessageを使用し、各ターンの顧客返答・登録音声・非常音声なしを確認。
- 近隣店舗質問では来店未確定。具体的な店舗案内後の来店・引取両分岐、同じ質問の繰り返し抑止、未回答採点の保持を確認。
- 9時の引取日時を維持したまま17時終了・18時納車の説明に回答。保険証券の確認了承と代車返却の説明了承を確認。
- 損傷確認142条件、意味理解優先62条件、複合来店提案44条件も成功。
- 実LLM API送信・ブラウザーでのマイク操作・音声の聴取は未実施。模範会話の顧客セリフと一字一句同じになる保証や満点保証はしない。

- 既存47テスト全件成功。構文検査・差分検査成功。
