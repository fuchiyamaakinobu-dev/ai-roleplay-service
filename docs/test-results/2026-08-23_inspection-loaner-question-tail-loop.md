- 代車手配の承諾と日程質問を同じ発話で行う応対

- 過去の質問文が補足発話へ合算される場合

- 後続の明確な代車承諾を、過去の日程質問だけで質問形と誤判定しない
- 「用意できますか」「用意できません」「確認します」は従来どおり未達とする
