# 入庫可能期間の日付を予約日として扱わないテスト

実施日: 2026-08-20

## 不具合

「8月11日以降であれば作業可能です」という入庫可能日の案内が会話履歴に残り、その後の「朝10時半はいかがでしょうか」という時刻提案と合成され、「8月11日10時半」の予約として誤認されていた。その結果、具体的な予約日が未確定なのに、お客様が「待っています。」と回答して次工程へ進んでいた。

## 修正

- 「以降」「以後」「から」「より」「まで」が続く日付を、予約日の候補から除外
- 入庫可能日と時刻だけでは予約を確定しない
- 日付が不足する場合は、登録済み音声の「何日の予定ですか？」で確認する
- 通常の具体的な月日・時刻提案は従来どおり予約として認識する

## 確認結果

- JavaScript構文確認: OK
- 入庫可能期間と予約日の分離: OK
- 既存QA一式: OK
