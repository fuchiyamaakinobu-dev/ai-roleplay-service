# 日頃のお礼の自然な言い回し判定テスト結果

実施日: 2026-08-23

## 対象

- 「日頃は大変お世話になり、ありがとうございます」の達成判定
- 「いつもありがとうございます」「お世話になっております」の達成判定
- 「お世話になります」の対象外判定
- 「いつも」「平素」を使った同等表現
- 「ご利用」「ご愛顧」を使った従来表現
- 一般的な「ありがとうございます」の誤判定防止
- 日頃のお礼工程と採点への接続

## 期待結果

- 継続的な関係と感謝を伝える自然な表現は、日頃のお礼として達成する
- 「いつもありがとうございます」「お世話になっております」は達成し、「お世話になります」は達成しない
- 単独の一般的なお礼は、日頃のお礼として達成しない
- 名乗りと日頃のお礼を同じ発話で伝えた場合も、両工程を達成できる
