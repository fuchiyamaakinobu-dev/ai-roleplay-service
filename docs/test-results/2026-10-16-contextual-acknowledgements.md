# 文脈に応じた相づち選択

## 変更

車検上級・応用の中立な短い返答だけを対象に、説明・理解・承諾の専用候補をLLMへ送る。既存会話処理で具体的な返答が必要になった場合は相づちに置換しない。登録文とMP3を組で選択し、発話内容だけを変更しない。

## 実Groq試験

| スタッフ発話 | 判定 | アプリでの返答 |
|---|---|---|
| 車検証と納税証明書をお持ちください。 | request / instruction | 分かりました。 |
| 受付内容をご案内いたします。 | explanation / listening | 分かりました。 |
| 予約のお手続きをこのまま進めてもよろしいでしょうか？ | question / consent | はい、お願いします。 |

APIへはテキストだけを送信。詳細結果はPC内tmp/live-acknowledgements-results.jsonに保存。

## 自動検証

- QA93本成功（HTTP検証を含む）。
- 上級・応用×LLM/OFF/通信失敗/保留で、実際のaddMessage経路を使い書類依頼と承諾の音声・表示を確認。
- 説明への同文反復回避、距離への具体的回答維持、二択・予約・本人確認・終話を保護。
- LLMの機能分類と候補の不一致を拒否。
- 荷物依頼の候補は理解音声に限定し、過去の連絡先音声への誤選択を防ぐ検証も維持。
