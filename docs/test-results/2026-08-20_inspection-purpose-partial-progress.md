# 車検用件の部分説明後に会話を進めるテスト

実施日: 2026-08-20

## 不具合

スタッフが「車検の時期が近くなりましたのでご連絡させていただきました」と用件を明確に伝えても、車種名がないため、お客様が「はい？ ご用件は何ですか？」と矛盾した聞き返しをしていた。

## 修正

- 車検と連絡理由が明確なら、車種または具体的な時期が不足していても会話を進める
- 「車検」がなくても、登録車種・登録満了日・予約意思確認がそろえば車検案内の文脈として会話を進める
- 車検の連絡理由だけを伝えた場合は、登録済みの「案内のはがきが来ていましたよ。」と返答する
- 同じ発話で予約意思も確認した場合は、その確認への回答を優先する
- 車種・車検時期の採点は、必要情報が不足しているため未達のまま残す
- 車検の用件自体が不明な発話には、従来の聞き返しを維持する

## 確認結果

- 車検用件の部分説明判定: OK
- 車検を含まない発話の除外: OK
- 構文確認および既存QA一式: OK
