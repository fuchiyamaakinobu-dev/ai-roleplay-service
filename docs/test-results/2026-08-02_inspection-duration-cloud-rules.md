# Firestore公開データと作業時間判定の整合テスト

実施日: 2026-08-02

## 原因

Firestoreの公開シナリオでは作業時間のキーワードが「1時間・60分」のままで、ローカル標準シナリオの「75分・90分」を上書きしていた。そのため、スタッフが90分を説明した後に店内待ちを補足しても、作業時間が未達のまま再質問されていた。

## 確認項目

- 旧公開キーワードを模したステップでも90分と店内待ちの組み合わせを達成扱いにする
- 90分だけでは達成扱いにしない
- 店内待ちだけでは達成扱いにしない
- 確定済みの作業時間表現と既存の車検誘致・12カ月点検QAを維持する
