# 会話記憶と未解決予約の回帰検証

対象は車検誘致・引取納車対応。公開版20261011-2の検証記録。

- `qa/check-inspection-conversation-memory.mjs` を追加。来店可否の言い換え、別発言の待ち方保持、自宅回答後と受付後の時刻了承、3距離の未解決予約・採点・終話、作業可能日案内と日付候補の区別を検証。
- 待てないと明示した説明を待ち可としないこと、お礼だけで追加作業後の説明完了としないことも検証。
- 既存を含む72本のチェックが成功。
- 管理者履歴から取得した過去8件・150発言を3距離×5シードで再実行（120条件・2,250発言）。未解決分岐のまま日時登録する矛盾は0件。最終の時刻文言調整後は代表8条件を再実行。
- 原文固定再生のため、新しいAI返答にスタッフ原文が応じていないケースは残る。全条件の終話を全返答の適切性と同一視しない。
- 出力した音声IDの登録ファイル欠落なし。新規音声・ブラウザー音声は追加していない。実際の音声再生とマイクは未検証。
- 個別スタッフの会話は公開リポジトリに保存しない。
