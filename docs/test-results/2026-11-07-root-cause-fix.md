# 2026-11-07 根本原因監査の修正検証（20261107-5）

## 変更

- 本人確認・通話許可・オイル希望を共通回答対象へ追加。正しい本人確認、通話許可、連絡先を別々に扱う。
- 文末句点や「今、お電話」の読点で文脈を失わない。前半の距離案内へ戻る原文再判定を削除。
- 距離の「何キロ〜でしょう」、オイルの「必要ございませんか」に回答。来店提案の「お休みの日」を理由質問と取り違えない。
- LLMがruleを返しても分析を渡す。引用が原文にあり、最後の回答対象と一致する場合に限り、未分類の距離・作業・連絡先の候補作成へ利用する。既知の分類を上書きしない。
- 共通候補の状態更新は最終音声採用後。非常代替や別音声なら回答済みにしない。距離だけ答えた場合は時間質問済みにしない。
- 未解決質問への工程末尾の「はい」は非常記録とし、工程を保持する。
- 終了保存へ非常記録・リリース番号・回答対象・候補・分析・採用・状態前後を渡す。保存時に電話番号をマスクし、判定不足と音声不足を区別する。

## 範囲と制限

- 本番のaddMessage/commitMessageを通すが、描画・実マイク・待ち時間はモック。実LLMへの新たな発話送信、実MP3聴取、実Firestoreへのテスト履歴投入は行っていない。
- 履歴の既存データに新しい判定情報を遡って補うことはできない。
- 状態の採用後更新は今回の共通候補経路が対象。全会話エンジンを全面的に書き換えたものではない。
- 音声追加、日付誤りの訂正動作、日次利用上限、採点配点、Firestore公開シナリオは変更しない。
- APIは新しい候補actionを扱うため、Workersを先に更新してからフロントを公開する。CLI公開時に既存Cloudflare認証を確認できず、ログイン待ちになった。公開完了は別途デプロイ結果で確認する。
