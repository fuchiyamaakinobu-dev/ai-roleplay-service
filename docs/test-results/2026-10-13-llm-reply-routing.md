# LLM返答連携テスト

- 自動テスト76本成功（既存・返答連携75本、HTTP比較サーバー1本）。
- LLM認識により追加整備申告と再確認の既存MP3を選択すること、音声登録テキスト・ID・ファイル存在を確認。
- 採点にLLMの判定を追加しないこと、既知表現はAPI不要、API無効・例外・判定なしの復帰を確認。
- 二重送信防止、リセット・手動終了・シナリオ切替後に古い返答が追加されないことを確認。
- ローカル画面からクラウド読込・履歴保存用スクリプトを除外。キーのパスがHTTP非公開であることを確認。
- 実API・ブラウザ：架空コード000000で12カ月点検を開始し「一緒に済ませておきたい整備はありますか？」を入力。「オイル交換もお願いします。」が表示され、追加整備段階へ進むことを確認。
- 最終UI調整：履歴なし表示、ローカル履歴処理をno-opとし、公開管理画面等への無効リンクを除去。ブラウザ再読込で確認。
- 音声実聴取、マイク入力、全場面のLLM精度は未検証。公開なし。
- 戻す場合：LLMチェックOFF、またはローカルサーバー停止。変更はfeature/llm-reply-routingに保存。
