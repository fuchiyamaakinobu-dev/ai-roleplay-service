# 車検誘致・漢数字時刻判定テスト結果

実施日: 2026-08-22

## 対象

- 車検誘致の日時確認
- 漢数字による具体的な時刻提案
- 「お昼」を含む午後時刻の判定
- 作業時間と予約時刻の誤認防止

## 確認結果

- 「お昼一時はいかがでしょうか」を13時の単一候補として認識
- 日付確定後は「では、その時間でお願いします。」へ進み、時刻質問を繰り返さない
- 「一時はいかがでしょうか」を具体的な時刻として認識
- 「作業は一時間程度です」は予約時刻として認識しない
- 「午前中ですと10時、お昼からですと4時」は従来どおり10時・16時の2候補として認識
