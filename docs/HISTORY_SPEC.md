# 実施履歴・社員コード仕様

最終確認日: 2026-07-28

## 確定: 社員コード

- ロープレ開始前に5桁の数字を必須入力する。
- 全角数字は半角数字へ変換する。
- 社員コードは集計用識別子であり、本人認証には使用しない。
- ロープレ中は変更できず、採点後に次回用として変更できる。

## 確定: 保存タイミング

- ロープレ開始時に`roleplayActivity`へ開始履歴を追加する。
- 採点時に`roleplayResults`へ採点結果を追加する。
- 同じロープレで終了処理が複数回呼ばれても、採点結果は1回だけ保存する。
- 保存失敗時も会話進行、採点表示、印刷を止めない。

## 確定: 保存項目

- 社員コード
- 実施日時、開始日時、終了日時、所要時間
- シナリオID、シナリオ名、進行方式
- 総合点
- 良かった点、改善点、判定ポイント、推奨トーク
- スタッフとAIお客様の会話ログ

実在のお客様名、電話番号、車台番号などの個人情報を入力・保存しない。

## 確定: 閲覧

- 登録済み管理者のGoogleアカウントだけが履歴を閲覧できる。
- 採点結果と開始履歴は、それぞれ最新500件を保存する。
- 管理者が履歴画面を開いたとき、501件目以降の古い履歴を自動削除する。
- 最新500件を読み込み、社員コードとシナリオで絞り込める。
- 表示中の採点結果をCSVで出力できる。
