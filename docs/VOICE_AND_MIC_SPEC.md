# 音声・マイク仕様

最終確認日: 2026-08-29

## 確定: お客様音声

- 登録済みMP3がある場合はMP3を再生する。
- MP3が再生できない場合でも会話進行を停止しない。
- 音声ファイルがない文章は、車検誘致と12カ月点検以外では対応ブラウザーの音声合成を使用できる。
- 12カ月点検は従来音声の登録済みMP3だけを使用し、未登録のお客様発話をブラウザー標準音声で自動生成しない。未登録の音声IDは、登録済みの自然な聞き返しMP3へ置き換える。
- 複数時刻から早い時刻を選ぶ返答、説明の食い違い解消後、家族相談後の再連絡、近い店舗・家族来店への同意、汎用の会話継続には登録済みMP3を使用する。
- 単一時刻の受諾、複数時刻から遅い時刻を選ぶ返答、午前希望を伝えて日付または具体的な時刻を確認する返答には登録済みMP3を使用する。
- 車検誘致は音読さんで作成した「まこと（カスタマーサポート）」の登録済みMP3を使用する。
- 車検誘致のお客様発話では、「すみません、」などの未収録文を自動追加してブラウザー標準音声で再生しない。聞き返しも登録済みの「まこと」MP3がある文章だけを使用する。
- 入庫日時が未確定のまま終話を繰り返した場合の「入庫する日と時間を教えてください。」「何月何日の何時に行けばよいですか？」も、登録済みの「まこと」MP3を使用する。
- 車検誘致の開始時は、専用の呼び出し音MP3を一度再生し、続けて登録済みの「はい、もしもし。」を再生する。呼び出し音は会話ログ上のお客様発話には含めない。
- 以前の四国めたん、剣崎雌雄、Fish Audioで作成した車検誘致音声は使用しない。
- お客様音声は同時に1件だけ再生する。次のお客様音声、シナリオ切替、やり直し、手動終了、スタッフ発話送信の際は、再生中の古い音声を停止する。
- 途中で停止した音声の終了処理から、別シナリオの会話や音声認識を再開しない。

## 確定: マイク開始

- 車検誘致は「ロープレ開始」を押すと、呼び出し音とお客様の「はい、もしもし。」を順番に再生し、その終了後に入力欄を消去して音声認識を開始する。
- お客様音声の再生終了後にスタッフ入力欄を消去する。
- 現在は終了から180ミリ秒後に音声認識開始を試みる。
- 音声自動再生をOFFにした場合も同じ流れで認識開始を試みる。
- 終話工程の発話が不完全な場合は自動採点せず、お客様の「はい。」の再生後も音声認識を再開する。車検誘致ではスタッフの最終発話に過去形の「ありがとうございました」を認識するか、利用者が「終了して採点」を押すまで入力欄とマイクを使用できる状態に戻す。「よろしくお願いいたします」「失礼いたします」だけでは自動終了せず、マイクを再開する。
- 予約日時確定後の単独の「かしこまりました。」「ありがとうございます。」など、AIお客様が返答せずスタッフの案内を続ける場面でも音声認識を自動再開する。「ありがとうございました。」は終話表現のため、この継続処理には含めない。
- 直前の音声認識が停止処理中で開始時に`InvalidStateError`となった場合は、120ミリ秒間隔で最大6回再試行し、一時的な停止競合でマイクをOFFのままにしない。
- 利用者がマイクを手動停止した場合は、保留中の自動再開を取り消す。

## 確定: AIお客様の反応速度

- スタッフの発話完了判定と、スタッフ発話の送信後からAIお客様の文字表示・音声再生を始めるまでの間隔を、画面上の1つの設定で変更できる。
- 選択肢は0.5秒・0.8秒・1秒・1.5秒・2秒とし、初期値は1.5秒とする。
- 選択値はブラウザーへ保存し、次回アクセス時も使用する。
- 音声入力では、発話完了判定ですでに待った時間を返答開始待ちとして扱い、自動送信後に同じ時間を重ねて待たない。テキスト送信では選択時間を返答開始前に待つ。
- 12カ月点検の開始直後など、スタッフ発話の直後ではないお客様発話には適用しない。
- 返答待ち中はスタッフ入力、マイク、送信を無効にし、二重送信を防止する。
- 短い設定では発話途中の間を発話終了と判断する可能性があるため、画面に注意を表示する。
- お客様音声終了後のマイク開始待ち180ミリ秒は変更しない。

## 確定: 音声認識

- Web Speech APIを使用する。
- 言語は`ja-JP`。
- 中間結果と連続認識を有効にする。
- 最終認識結果の後、AIお客様の反応速度で選択された時間だけ待って文章の完結を判定する。
- 完結していれば自動送信する。
- 「それから」「それと」「それともし」「そして」「続いて」「ええと」「えっと」など、続きを示す接続語で終わる場合は、句点があっても自動送信せず認識を継続する。
- 「お使いのヤリスが。」など助詞で終わる言いかけも完成文とせず、AIお客様を割り込ませない。
- 途中と判定した場合はAIの相槌を再生せず、現在の音声認識を中断しないでスタッフの続きを待つ。Web Speech APIが発話途中の区切りを最終認識結果として返しても、スタッフの発話へ「はい」を重ねない。
- 認識の`end`発生後、必要な場合は250ミリ秒後に再開する。
- 音声認識非対応ブラウザーではテキスト入力を使用する。

## 確定: 現在の無音判定

音量や無音継続時間を測定する独立した無音検出はない。現在の終了判断はブラウザーの最終認識結果と文章完結判定に依存する。
