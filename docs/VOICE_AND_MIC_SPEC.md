# 音声・マイク仕様

最終確認日: 2026-08-01

## 確定: お客様音声

- 登録済みMP3がある場合はMP3を再生する。
- MP3が再生できない場合でも会話進行を停止しない。
- 音声ファイルがない文章は、対応ブラウザーで音声合成を使用できる。
- 12カ月点検は従来音声を使用する。
- 複数時刻から早い時刻を選ぶ返答、説明の食い違い解消後、家族相談後の再連絡、近い店舗・家族来店への同意、汎用の会話継続には登録済みMP3を使用する。
- 単一時刻の受諾、複数時刻から遅い時刻を選ぶ返答、午前希望を伝えて日付または具体的な時刻を確認する返答には登録済みMP3を使用する。
- 車検誘致は音読さんで作成した「まこと（カスタマーサポート）」の登録済みMP3を使用する。
- 車検誘致のお客様発話では、「すみません、」などの未収録文を自動追加してブラウザー標準音声で再生しない。聞き返しも登録済みの「まこと」MP3がある文章だけを使用する。
- 車検誘致の開始時は、専用の呼び出し音MP3を一度再生し、続けて登録済みの「はい、もしもし。」を再生する。呼び出し音は会話ログ上のお客様発話には含めない。
- 以前の四国めたん、剣崎雌雄、Fish Audioで作成した車検誘致音声は使用しない。
- お客様音声は同時に1件だけ再生する。次のお客様音声、シナリオ切替、やり直し、手動終了、スタッフ発話送信の際は、再生中の古い音声を停止する。
- 途中で停止した音声の終了処理から、別シナリオの会話や音声認識を再開しない。

## 確定: マイク開始

- 車検誘致は「ロープレ開始」を押すと、呼び出し音とお客様の「はい、もしもし。」を順番に再生し、その終了後に入力欄を消去して音声認識を開始する。
- お客様音声の再生終了後にスタッフ入力欄を消去する。
- 現在は終了から180ミリ秒後に音声認識開始を試みる。
- 音声自動再生をOFFにした場合も同じ流れで認識開始を試みる。

## 確定: お客様返答までの間隔

- スタッフ発話の送信後から、AIお客様の文字表示と音声再生を始めるまでの間隔を画面で変更できる。
- 選択肢は、すぐ・0.5秒・1秒・1.5秒・2秒・3秒とし、初期値は1秒とする。
- 選択値はブラウザーへ保存し、次回アクセス時も使用する。
- 12カ月点検の開始直後など、スタッフ発話の直後ではないお客様発話には適用しない。
- 返答待ち中はスタッフ入力、マイク、送信を無効にし、二重送信を防止する。
- 音声認識結果の完結を判定する2秒、お客様音声終了後のマイク開始待ち180ミリ秒は変更しない。

## 確定: 音声認識

- Web Speech APIを使用する。
- 言語は`ja-JP`。
- 中間結果と連続認識を有効にする。
- 最終認識結果の後、2秒待って文章の完結を判定する。
- 完結していれば自動送信する。
- 途中と判定した場合は「はい」と相槌を再生して認識を再開する。
- 認識の`end`発生後、必要な場合は250ミリ秒後に再開する。
- 音声認識非対応ブラウザーではテキスト入力を使用する。

## 確定: 現在の無音判定

音量や無音継続時間を測定する独立した無音検出はない。現在の終了判断はブラウザーの最終認識結果と文章完結判定に依存する。
