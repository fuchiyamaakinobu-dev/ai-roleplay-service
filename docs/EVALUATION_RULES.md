# 評価・採点ルール

最終確認日: 2026-08-20

## 確定: 共通

- 得点範囲は0〜100点。
- 達成項目は会話全体で一度でも認識されれば加点対象となる。
- 良かった点、改善点、判定ポイント、推奨トークを表示する。
- 12カ月点検では、未達項目だけを使った「次回の改善トーク」を表示し、達成済み項目を改善指摘として再表示しない。
- 車検誘致では、現在の順序型シナリオ全体の推奨トークを表示する。
- 合格・不合格の固定基準はまだ設けない。
- 社員コードと採点履歴の保存有無は得点計算に影響させない。
- 音声認識で主要語がひらがなになった場合は、会話表示と保存ログの原文を変えず、判定時だけ漢字・カタカナの標準表記へ補正する。対象は氏名・店舗名、車検・点検、都合・予約、作業時間、走行距離、代車、追加作業・車両状態、持参品、ロックナット、事前連絡、12カ月点検の来店提案に使う主要語と、月日・時刻・分数のひらがな数詞とする。
- 補正後も、店舗名と担当者名、具体的な日付と時刻、複数の必須キーワード群など、各項目の既存達成条件は緩和しない。

## 確定: 12カ月点検

配点:

- 依頼を受け止める: 8点
- その他ご用命・気になる点: 15点
- 作業時間: 8点
- 引取希望の事情を受け止める: 13点
- 来店メリット: 13点
- 土日などの提案: 13点
- 他店舗などの提案: 8点
- 選択肢を残す: 8点
- 次の約束: 14点

お客様の理由に合わない提案項目は満点条件から除外し、該当する配点合計を100点換算する。仕事理由では他店舗提案を必須にせず、距離・運転不安では土日提案を必須にしない。

引取希望の事情は、お客様が「畑が忙しい」「仕事で来店が難しい」「距離がある」「運転に不安がある」などと話した内容を、スタッフが「畑がお忙しいのですね」「お仕事で来店が難しいのですね」などと受け止めれば達成とする。理由を改めて質問したり、詳しい事情を深掘りしたりすることは必須としない。従来の理由確認質問も判定上は有効とするが、改善トークでは事情を受け止める応対を推奨する。

作業時間を説明した後にオイル交換などの追加作業を受け付けた場合は、作業時間項目を再確認必要とする。「追加作業を含めても1時間程度」など変更後の時間を案内するか、「作業時間に変更はありません」と再案内すれば達成扱いに戻す。再案内がない場合も会話は止めないが、作業時間8点は未達とする。追加作業を先に受け付け、その後で作業時間を説明した場合は通常どおり達成とする。

入庫日時は具体的な日付と1つの時刻がそろった場合に確定する。複数の時刻候補がある場合は、お客様が「では、早いほうでお願いします」と返答し、最も早い時刻を選ぶまで未確定とする。「午前」「午後」などの時間帯だけでは確定しない。

減点:

- 来店提案前に引取を確定: 25点
- 来店を強く迫る: 10点
- 引取を強く拒否: 10点
- お客様の事情に提案が合わない: 15点

## 確定: 車検誘致

17項目の配点合計は100点。

- 必要キーワードグループをすべて満たすと項目達成。
- 日時提案は「月・日・時」の具体値が必要。
- 予約復唱は、先に確定した月・日・時との一致が必要。
- 確定した月・日・時だけを正しく復唱した場合は、氏名や締め表現が不足していても会話を先へ進める。ただし予約復唱の採点は未達のままとし、日時が不一致の場合は聞き返す。
- 案内不足による聞き返し1回につき2点減点。
- 聞き返し減点は最大20点。
- 入庫日時確定後の任意項目は、省略しても聞き返し減点を付けない。
- 具体的な月日と時刻の予約提案へ進んだ場合は、それ以前の未確認項目へ後戻りしない。挨拶、本人確認、名乗り、日頃のお礼、車検案内、走行距離、追加作業、予約手続き時間などを省略しても会話進行は止めず、各項目を未達として採点する。省略だけを理由とする聞き返し減点は付けない。
- 入庫日時が確定した後は、待ち方、荷物・持参品、ロックナット、10分または15分前来店、3日前連絡、予約復唱などが未確認でも終話できる。省略項目は未達として採点する。
- 本人確認はお客様名を必要とし、「お客様でしょうか」だけでは達成にしない。携帯電話への発信では本人確認を省略しても会話を止めず、本人確認4点を未達として次の名乗りへ進む。省略そのものによる聞き返し減点は付けない。
- 名乗りは店舗名と担当者名の両方を必要とする。
- 車検満了日の説明は、具体的な満了日を案内すれば達成とする。作業可能日の案内は加点条件に含めず、省略しても減点しない。
- 満了日が未案内のまま曜日希望だけを質問した場合は、曜日質問に回答するお客様発話へ切り替えても、満了日項目は達成扱いにしない。期限確認の聞き返しとして従来どおり減点する。
- 「走行距離・作業時間・店内待ち」7点は、現在の走行距離を質問し、60分、75分、90分（1時間、1時間15分、1時間30分を含む）のいずれかを案内し、店内待ちも説明した時点で達成とする。走行距離の確認を省略した場合は達成にしないが、お客様には関係しないスタッフの判断材料であるため、聞き返し減点を付けず次へ進む。
- 走行距離の確認は「走行距離」「距離数」「何キロ」「何km」などを含む質問を必要とする。想定回答は初回車検・30,000kmの「今、3万キロくらいです。」とし、距離について質問していない単なる説明は確認済みにしない。
- ロックナット用具は、ロックナットキー、ロックキー、アダプター、外す工具、専用工具、外す道具などの同義表現を認識する。一般的な「工具」「道具」「キー」はロックナット等の文脈を伴うことを必要とする。
- 予約手続き時間は10分の具体値を必須とせず、「もう少しお時間ありますか」「このまま予約を進めてもよろしいですか」など、時間または予約手続きの文脈で了承を求める質問を達成とする。時間がかかるという説明だけで、了承確認がない場合は達成しない。
- 前工程が未確認でも、「予約」「手続き」を含む明確な予約時間の了承確認が行われた場合は、その質問を達成として「大丈夫ですよ。」と回答し、未確認項目へ戻らず日時調整へ進む。省略した前工程は未達として採点し、聞き返し減点は付けない。
- 「車検の方はお決まりでしたでしょうか」「車検はもう決められましたか」など、車検の予約意思を尋ねる疑問文は都合確認として達成する。質問でない単なる「車検は決まりました」は達成しない。
- 予約手続き時間の了承確認を省略して具体的な日時提案へ進んだ場合、了承確認は未達のまま採点するが、案内不足の聞き返し減点は付けず、会話は日時調整へ進める。
- 具体的な月日・時刻がなくても、曜日と希望時間帯を質問して予約日時調整へ入った場合は、予約手続き時間の了承確認を未達のまま会話だけ日時調整へ進める。ただし、曜日・時間帯だけでは具体的な予約日時の得点は与えない。
- 日頃のお礼を言い間違えて未達のまま次工程へ進んだ後でも、スタッフが正しいお礼を言い直した場合は、会話全体の証拠として日頃のお礼を達成に訂正する。お礼だけの言い直しを車検案内不足として扱わず、「ご用件は何ですか？」を返さない。
- 「いつぐらい」「何日」「何時」と「都合」「希望」を組み合わせて希望日時を質問した場合も、予約手続き時間の了承確認は未達のまま日時調整へ進める。ただし、具体的な月日と時刻が提示されるまでは予約日時の得点を与えない。
- 平日・土日・週末・曜日について希望を選ばせる質問も、予約手続き時間の了承確認を未達のまま日時調整へ進める。曜日希望への回答だけでは予約日時の得点を与えない。
- ロックナット用具と早めの来店案内は別条件とし、来店時間は10分前または15分前のどちらでも達成とする。
- 待ち方と車両状態の確認は、対象語だけでなく質問・確認の形を必要とする。
- 車両状態の確認を予定より前の工程で行った場合も、質問・確認の形と対象語を満たせば達成として保持する。お客様のオイル交換希望へ回答した後、同じ車両状態確認を再度要求しない。
- オイル交換希望の後にスタッフがその他の追加作業を再確認した場合は、お客様が「そのほかは大丈夫です。」と回答する。作業時間など同じ工程で説明済みの内容は保持し、店内待ちなど残る未確認項目だけをその後に確認する。
- スタッフが作業時間とともに店内待ちを選択肢として積極的に提案した分岐では、代車予約を対象外とする。代車予約6点を満点条件から除外して残りの配点を100点換算し、代車未案内を改善点に表示しない。同じ回答内で代車も案内した場合は通常どおり判定する。
- お客様が店内待ちの可否を尋ね、スタッフが店内待ち可能と回答した分岐では、外出に備えた代車希望へ進むため、代車予約を対象外にせず通常どおり採点する。
- 上記の分岐でお客様が代車を明確に希望した後は、スタッフが代車の用意・準備・手配を明確に承諾すれば代車項目を達成とする。この場合は「早め」「予約」の語を必須としない。否定回答や「確認します」だけの回答は達成にしない。
- 直前にお客様が代車を明確に希望している場合は、「大丈夫ですよ。ご用意させていただきます」「空いてますよ」「大丈夫です」のようにスタッフが「代車」を省略しても、手配可能の肯定回答として達成とする。代車希望の文脈がない場合、質問形の「大丈夫ですか」、空きがない旨の否定表現は達成にしない。
- お客様の代車希望に対してスタッフが用意を承諾した場合は、待ち方も「代車利用」として確認済みにする。後工程の店内待ち確認を重ねて要求しない。
- 入庫日時確定後にスタッフから「代車をご準備させていただいております」など手配済みの肯定案内をした場合も、待ち方を「代車利用」として確認済みにする。質問形、手配確認中、用意できない案内は確定扱いにしない。
