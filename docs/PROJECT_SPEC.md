# プロジェクト仕様

最終確認日: 2026-07-28

## 確定: 目的

自動車販売店スタッフが、お客様役との音声またはテキスト会話を通じて応対を練習し、会話後に採点と改善点を確認できるWebアプリとする。

## 確定: 現在の対象シナリオ

1. 12カ月点検・来店促進
2. 車検誘致・電話フォロー

現在のコードに車両販売シナリオは存在しない。車両販売編は`docs/SALES_FLOW.md`で未確定として管理する。

## 確定: 現在の提供機能

- お客様発話の表示と音声再生
- AIお客様の反応速度設定（スタッフの発話完了判定と返答開始待ちを共通設定で調整、0.5秒・0.8秒・1秒・1.5秒・2秒、初期値1.5秒、ブラウザー保存）
- スタッフの音声認識またはテキスト入力
- 状態遷移とキーワード判定による会話進行
- 画面上部へ固定する確認項目の進捗表示と表示ON/OFF
- 車検誘致17採点項目の判定語・言い換え・不足例・音声認識補正を検索できる判定単語帳
- 車検誘致では、お客様名・車種・車検満了日・作業可能日を画面上部へ固定表示
- シナリオ別の採点、改善点、推奨トーク
- A4縦・白黒を前提とした会話と評価の印刷
- 6桁の社員コードによる実施者識別
- ロープレ開始履歴、点数、評価、会話ログのFirestore保存
- 管理者専用の実施履歴一覧、絞り込み、CSV出力
- Google管理者ログインによるシナリオの下書き保存と公開
- Firestore公開データが取得できない場合のローカルデータ利用

## 確定: 技術構成

- 静的HTML、CSS、JavaScript
- GitHub Pages
- Firebase Authentication
- Cloud Firestore
- Web Speech API
- MP3音声およびブラウザー音声合成

OpenAI APIや外部LLMは現在使用していない。お客様役と採点はルールベースである。

進捗表示は練習用の補助機能とし、初期値はONとする。OFFにすると上部の確認項目と現在の段階を隠す。選択はブラウザーに保存するが、会話分岐、採点、音声には影響させない。

車検誘致のお客様情報は進捗表示とは別の参照情報とし、進捗表示をOFFにしても表示する。シナリオを切り替えた場合は、選択中のシナリオデータに合わせて表示または非表示を更新する。

## 確定: データの基準

- ローカル標準シナリオ: `scenario.js`
- 音声ID、音声文、MP3対応: `audio-db.js`
- 公開中シナリオ: Firestore `roleplay/public`
- 管理中の下書き: Firestore `roleplay/draft`
- ロープレ開始履歴: Firestore `roleplayActivity`
- 採点結果と会話ログ: Firestore `roleplayResults`

社員コードは6桁の数字をロープレ開始前に必須入力とする。社員コードは集計用識別子であり、本人認証や管理者権限には使用しない。履歴は追加専用とし、閲覧は登録済み管理者に限定する。採点結果と開始履歴はそれぞれ最新500件を保存し、管理者が履歴画面を開いたときに古い履歴を自動整理する。
